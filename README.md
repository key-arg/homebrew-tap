# Key Arg Homebrew tap

```bash
brew install key-arg/tap/statable
```

## What is here

| Cask | What it is |
|---|---|
| `statable` | [statable-cli](https://github.com/key-arg/statable-cli) — read your Statable analytics from a terminal, a script, or CI |

Casks in this tap are written by the release pipeline of the project they
belong to, not by hand. Edit the project, tag a release, and the cask follows.
